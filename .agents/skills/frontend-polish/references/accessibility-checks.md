# Frontend Polish — Accessibility and Interaction Checks

## Keyboard
Interactive controls reachable; logical focus order; visible focus; no traps; dialogs/menus manage focus appropriately; Escape where expected.

## Semantics
Prefer native elements; buttons are buttons, links are links; controls have labels; heading/table structure is sensible.

## Images/icons
Meaningful images have useful alternatives; decorative imagery does not add noise; icon-only controls have accessible names.

## Errors/status
Errors are associated with fields when practical; important status changes are perceivable; critical meaning is not color-only.

## Contrast/zoom
UI remains usable with browser zoom and fixed dimensions do not hide critical content; flag obviously insufficient contrast.

## Motion/touch
Respect reduced motion; avoid flashing/aggressive motion; controls are practically tappable; important interactions are not hover-only.

Do not claim formal WCAG conformance unless a dedicated conformance audit was actually performed.
